# Audi authentication fixtures

Synthetic pages and responses shaped like the VW Group identity service, used by the unit tests
of `vag2mqtt-connector-audi`. Every value (`csrf-fixture`, `hmac-fixture`, `access-fixture`, the
`driver@example.test` address) is invented; nothing here came from a real account.

Once the WP-06 login spike has produced masked traces of the real flow, the shapes here are
corrected to match them.
